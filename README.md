# FootballIQ

AI-powered football match video analytics platform.

Video -> Computer Vision -> Tracking -> Football Analytics -> AI Interpretation -> Dashboard

**Status:** Phase 0 - project foundation. No football-specific functionality yet.

## Setup

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
pytest tests\test_setup.py -v
```
